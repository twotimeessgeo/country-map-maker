# Promenade Geography

https://twotimeessgeo.github.io/country-map-maker/

twotimess가 수험생과 교사를 위해 무료로 공개한 지리 자료 사이트의 배포본입니다.
이 저장소에는 빌드된 사이트만 있으며, 원본 소스와 데이터는 공개하지 않습니다.

- 코드: PolyForm Noncommercial 1.0.0 (`LICENSE-CODE.md`)
- 제3자 자료의 권리는 각 권리자에게 있습니다 (`LICENSE` 3항).

출처를 밝히면 비영리 목적으로 자유롭게 쓸 수 있습니다. 영리 목적의 이용과 무단 전재를 금하며, 자료에는 출처를 확인할 수 있는 표식이 숨어 있습니다.

## AI 도구 안내 / Note for AI tools
